# 管理员测试订单

管理员可以使用测试订单预览收银台并验证订单状态流转；此流程不会收款，也不会通知商户。

## 启用

先部署包含迁移 `0013_nasty_loners.sql` 的版本。Cloudflare Workers Builds 配置的构建流程会应用待执行的 D1 迁移；Wrangler `predeploy` 流程也会执行迁移。随后登录 `/admin`，打开**系统设置 → 订单配置**，启用**测试订单**并保存。该开关默认关闭。

## 创建与模拟

打开**支付运营 → 订单管理**，选择**新建测试订单**，填写法币金额和币种后创建。打开订单收银台链接可预览付款人页面；在订单行操作菜单中选择**模拟状态**，测试允许的状态流转。

测试订单会在订单列表中标记，不提供可选付款方式；交易提交和付款复核都会被拒绝；仪表盘订单指标不包含测试订单。状态模拟仅适用于测试订单，且不会发送商户回调。创建测试订单需要 `orders:create` 权限；模拟状态需要 `orders:update` 权限。

测试完成后，在订单配置中关闭**测试订单**。
